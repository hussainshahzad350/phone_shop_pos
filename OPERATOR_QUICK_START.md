# Operator Quick Start

1. Open the app and wait for the startup screen to finish.
2. Go to **Settings** and confirm **Startup Health** says **Healthy**.
3. Run **One-Click Backup** before the first customer.
4. Complete sales normally.
5. If a receipt does not print:
   - open **Settings**
   - check **Invoice Print Queue**
   - retry the failed receipt after checking the printer
6. Do not close the app while a save, backup, restore, or print operation is still in progress.
7. Before restoring a backup, always create a fresh backup first.
8. At end of day, run another backup and confirm there are no unresolved failed receipts.
